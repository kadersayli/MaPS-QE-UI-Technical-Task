# Bug Report

**Severity:** Critical
**Page:** / localhost (for local test)
**Area:** Missing page title

##### Description

The page does not have a < title > element identifying its purpose.

##### Steps to reproduce

1. Open the webpage.
2. Inspect the browser tab or the page's < head > element.
3. Observe that the page has no descriptive title.

##### Actual result

The page has no < title > element.

##### Expected result

The page has a descriptive title that identifies its topic or purpose.

##### User impact

Users, particularly screen-reader users, may struggle to identify the page when switching between tabs or browsing their history.
